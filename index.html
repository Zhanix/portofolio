Tugas Akhir Skripsi Sarjana Terapan • HKI Kemenkumham Terdaftar

Rancang Bangun Pembersih Otomatis Cat Litter Box Berbasis Internet of Things dengan Deteksi Berat

Kotak pasir kucing otomatis pintar yang dirancang untuk membersihkan kotoran secara otonom berbasis deteksi berat kotoran. Mengintegrasikan sensor penimbang load cell (HX711) di bawah wadah penampung limbah, sensor infrared obstacle untuk keselamatan kucing, mekanisme penggaruk motor stepper NEMA 17 (driver DRV8825) dan lead screw, pintu penutup servo MG996R, serta sinkronisasi telemetri dua arah via Firebase Realtime Database ke aplikasi Android SmartCatLitterBox.

Arsitektur & Spesifikasi Sistem (Sesuai Skripsi)

Mikrokontroler
NodeMCU ESP8266 (Tensilica 32-bit Xtensa LX106 @ 80 MHz, Flash 4MB) sebagai unit kendali logika, pembacaan sensor non-blocking (millis), dan komunikasi Wi-Fi.
Sensor Berat
Load Cell 5kg + ADC HX711 24-bit di bawah tempat sampah untuk menimbang akumulasi kotoran (threshold batas penuh 500 gram / 0.5 kg).
Penggerak Sisir
Motor Stepper NEMA17 (torsi 40 N.cm) + Driver DRV8825 dengan lead screw 100 cm (jarak jelajah 33 cm) menggunakan profil percepatan trapesium.
Katup Wadah
Motor Servo MG996R (Metal Gear) mengontrol buka (150°) dan tutup (0°) pintu kompartemen sampah dengan jeda pengaman lockout 2 detik.
Sensor Aman
Infrared Barrier Obstacle Sensor mendeteksi kucing (rentang 2–8 cm) dengan jeda 3 menit pasca-kucing keluar dan Safety Lock otomatis jika terhalang ≥90 detik.
IoT & Cloud
Firebase Realtime Database untuk transmisi data dua arah (telemetri sensor & kontrol motor) dan Firebase Cloud Messaging (FCM) untuk push notification.
Aplikasi Mobile
Aplikasi Android SmartCatLitterBox (Android Studio) untuk monitoring real-time berat kotoran, deteksi kucing, status alat, dan tombol kontrol manual.
Regulasi Daya
Adaptor DC 12V 5A dengan dual step-down XL4005: 12V stepper VMOT, 5.2V logika ESP8266/HX711/IR, dan 5.2V dedicated untuk servo MG996R.

Teknologi & Komponen Terpasang
