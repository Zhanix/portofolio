## 🌟 Sorotan Utama Portofolio

### 1. Studi Kasus Rekayasa Skripsi: Smart Cat Litter Box IoT
* **Judul Tugas Akhir:** Rancang Bangun Pembersih Otomatis Cat Litter Box Berbasis Internet of Things dengan Deteksi Berat.
* **Arsitektur Sistem:**
  - **Kontrol Logika:** NodeMCU ESP8266 (Tensilica 32-bit LX106 @ 80 MHz, Flash 4MB, algoritma non-blocking `millis()`).
  - **Sensor Berat:** Load Cell 5kg + ADC HX711 24-bit (kalibrasi akurat untuk limbah kotoran kucing, ambang batas 500 gram).
  - **Mekanisme Penggaruk:** Motor Stepper NEMA17 (torsi 40 N.cm) + Lead Screw T8 (lintasan gerak 33 cm).
  - **Sistem Keamanan:** Sensor Infrared Obstacle Detector (pencegah operasi saat hewan berada di dalam wadah).
  - **Konektivitas & Aplikasi:** Firebase Realtime Database, FCM Push Notification, dan aplikasi Android monitoring (Java).
* **Legalitas:** Terdaftar resmi pada **HKI Kemenkumham RI** (Buku Panduan, No. EC002026098216) dan terbit di **Jurnal JAIEA SINTA Rank 5** (Vol. 5 No. 3, Juni 2026).

## 🚀 Menjalankan Secara Lokal

Portofolio ini dibangun murni menggunakan standar web modern (**Vanilla HTML, CSS, dan JavaScript**) tanpa dependensi package manager yang rumit.

1. **Clone repositori:**
   ```bash
   git clone https://github.com/Zhanix/porto.git
   cd porto
   ```

2. **Buka di browser:**
   - Cukup klik ganda pada file `index.html`, atau
   - Jalankan server HTTP lokal sederhana:
     ```bash
     python -m http.server 8080
     ```
   - Buka `http://localhost:8080` pada peramban web.
